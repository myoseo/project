# Python 주식 백테스트 프로젝트

CSV 파일에 저장된 종가 데이터를 기반으로 5일 이동평균선과 20일 이동평균선의 골든크로스/데드크로스 전략을 백테스트하는 예제 프로젝트입니다.

## 특징

- Python 표준 라이브러리만 사용합니다.
- `csv` 모듈로 `data.csv`를 읽습니다.
- 외부 라이브러리를 사용하지 않으므로 `pip install`이 필요 없습니다.
- 실시간 자동매매 기능은 포함하지 않습니다.
- CSV 기반 백테스트만 수행합니다.
- 초기 자금은 1,000,000원입니다.
- 5일 이동평균선과 20일 이동평균선을 직접 계산합니다.
- 5일 이동평균선이 20일 이동평균선을 상향 돌파하면 전액 매수합니다.
- 5일 이동평균선이 20일 이동평균선을 하향 돌파하면 전량 매도합니다.
- 최종 평가금액, 총 수익률, 거래 횟수, 매수/매도 내역을 출력합니다.

## 파일 구성

```text
main.py
data.csv
requirements.txt
README.md
```

## 설치 방법

Python 3.10 이상 사용을 권장합니다. 별도의 패키지 설치는 필요하지 않습니다.

```bash
python --version
```

## 실행 방법

```bash
python main.py
```

실행하면 `data.csv`의 `date`, `close` 컬럼을 읽어 백테스트 결과를 콘솔에 출력합니다.

## CSV 형식

`data.csv`는 아래 형식을 따릅니다.

```csv
date,close
2024-01-02,10000
2024-01-03,9950
```

- `date`: 거래일
- `close`: 종가

## 주의사항

이 프로젝트는 학습용 CSV 기반 백테스트 예제입니다. 거래 비용, 세금, 슬리피지, 배당, 액면분할 등 실제 투자 환경의 모든 요소를 반영하지 않으며, 실시간 자동매매를 수행하지 않습니다.
